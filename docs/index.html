Auto WiFi Connector

自动 WiFi 断网重连 · RUST + TAURI 2

笔记本的 WiFi 有时明明显示已连接，网页却打不开。Auto WiFi Connector 周期性探测互联网连通性， 一旦判定断网，便取所有「可见且已保存密码」的网络，按信号强度依次尝试连接， 直到真正恢复上网；一轮未恢复则等待后继续，直到成功为止。

工作原理 How It Works

每 10 秒: WiFi 已关联 且 任一探测端点可达?
  ├─ 是 → 保持监控
  └─ 否 → 候选 = 可见网络 ∩ 已保存配置, 按信号降序
           依次: netsh 连接 → 等待关联(≤12s) → 验证连通性
           任一成功即恢复; 全部失败则 15s 后开始下一轮
  • 连通性探测：向多个固定 HTTP 204/200 端点发起请求；结合 WiFi 关联状态综合判定，避免本机代理虚拟网卡（TUN 模式）造成的误判
  • 时间有界：探测整体限时返回，网卡切换引起的 DNS 长时间阻塞不会使监控停摆
  • 跨区域兼容：netsh 输出解析同时兼容中英文系统，含非 ASCII 字符的 SSID 也能正确处理

后台运行 Tray & Autostart

关闭窗口后程序隐藏到系统托盘继续监控；右键托盘图标可选择「显示窗口」或「退出」。 程序默认注册开机自启，可在界面中关闭。

使用说明 Usage

  • 开启「自动断网重连轮询」开关，程序即开始监控；关闭窗口不影响运行
  • 只有「已存密码」的网络才会被用于重连——请事先在 Windows 中连接并保存常用 WiFi 的密码
  • 「开机自启」默认开启，登录后自动在托盘待命
  • WiFi 无线电被关闭（飞行模式等）时，程序会自动尝试打开

安装 Install

从 Releases 下载 zip 解压即用。程序未购买代码签名证书（多数开源项目相同），首次运行时 Windows 可能显示 SmartScreen 提示「Windows 已保护你的电脑」，点击「更多信息 → 仍要运行」即可。

每个 Release 附带 .sha256 校验文件，可用 certutil -hashfile 文件名 SHA256 核对下载完整性。

构建 Build

环境要求：Rust 1.77+、Windows 10/11。

git clone <repo-url>
cd auto_wifi_connector/src-tauri
cargo run                 # 调试运行
cargo test                # 单元测试
cargo tauri build         # 产出安装包（需 tauri-cli）
参数值说明
CHECK_INTERVAL10s连通性检测周期
ASSOCIATE_TIMEOUT12s单次连接等待关联完成的超时
ROUND_DELAY15s一轮候选全部失败后的等待
